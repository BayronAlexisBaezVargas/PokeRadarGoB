## 2. Fuentes de Datos y APIs de la Comunidad
El funcionamiento en tiempo real de esta plataforma es posible gracias al increíble trabajo de recolección de datos que realizan los siguientes proyectos comunitarios:

* **[Leek Duck](https://leekduck.com/):** Información sobre rotación de jefes de incursión, investigaciones y eventos actuales.
* **[ScrapedDuck API](https://github.com/bigfoott/ScrapedDuck):** Proyecto de código abierto que provee un feed estructurado (JSON) basado en los datos de Leek Duck.
* **[Pokémon GO Hub](https://pokemongohub.net/):** Base de datos integral sobre estadísticas, counters, parámetros de captura e información del metajuego.
* **[PokéAPI](https://pokeapi.co/):** API RESTful educativa y de código abierto que proporciona los datos base de especies, tipos elementales, evoluciones y sprites originales.
